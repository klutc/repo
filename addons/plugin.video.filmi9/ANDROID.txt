Android TV resolver update:
- Filmi9's Vidsrcme (`vidsrcme.ru`) URLs use the native VidSrc resolver, which follows the mirror/player handoff and decrypts the stream API without Chrome. Tested with Scrubs S01E01 on the current Vidsrc player.
- Playback items carry the English series title, IMDb ID, season and episode in Kodi's video metadata so subtitle add-ons can search automatically instead of relying on a Bulgarian stream filename.
- Vsembed follows the public nested-player API, decodes its ChaCha20/WASM data with portable Python, obtains the stream-host token and selects a working HLS server. No browser or WASM runtime required.
- When Vsembed does not provide subtitle tracks, the add-on searches OpenSubtitles for Bulgarian subtitles using the movie's IMDb ID.
- Byse/FileMoon follows embed_frame_url, registers an ephemeral P-256 key with the site, completes the automatic computation check, and decrypts the returned playback data using the existing ResolveURL AES-GCM library. This may take up to four minutes on the first attempt; Cancel stops the check. Valid site-issued tokens are cached for repeat playback (up to ten minutes). No visual CAPTCHA is bypassed or automated.
- VOE uses the host-provided MP4 stream by default on Android, after a small Range probe; falls back to HLS when MP4 is unavailable. Settings can disable MP4. Bulgarian captions are retained.
- VIDM and PlayM retain direct HTTP playback; ABS uses the installed resolver.
- On Android, Upbolt and StreamTape-family hosts open in the WebView helper so you can complete a visible Cloudflare check. Kodi captures a direct media URL and subtitle URL when exposed; host behavior varies, so this fallback is experimental. Linux retains the existing resolver/browser behavior.
- VidSrcEmbed stays on the native resolver first. If it reports a Cloudflare/Turnstile challenge on Android, the WebView helper opens the same page as a fallback.
Validation: real HLS manifests, variants and small video samples for Vsembed (Aquaman/The Tearsmith) and VOE (eight current movies), native Byse/FMооn manifests, FMoon Bulgarian HLS captions, and a Bulgarian Vsembed subtitle downloaded and parsed as 1,218 cues. Android TV hardware verification remains necessary. Desktop browser fallback is retained for other sources on Linux.
