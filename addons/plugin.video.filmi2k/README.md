# Filmi2K by Klutc

Kodi add-on for browsing and searching movies and series from https://www.filmi2k.com/. It reads the site's public WordPress pages, metadata and video embed URLs. Playback uses the installed Find Stream URL resolver; supported hosts depend on the site's current source.

The site lists series episodes as individual video posts. Search results identify episode metadata from season/episode titles where available.
