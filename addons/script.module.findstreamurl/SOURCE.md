# Find Stream URL in klutc Repo

Snapshot of the working local Find Stream URL installation, packaged on 2026-10-13.
Original provider: Forked by MartinStZ. Upstream ResolveURL: https://github.com/Gujal00/ResolveURL

This snapshot includes local host resolver adjustments used by FilmiZip/Filmi9 (including ABS and Byse). The package version is 2026.10.13.01 so Kodi can upgrade earlier installations to this snapshot. All Python sources are included in this repository and in the ZIP; original copyright notices are retained. The GPL-3.0-or-later license is included in LICENSE. Bundled TLSLite AES-GCM code retains its separate license in lib/resolveurl/lib/aesgcm/LICENSE.

No Kodi user profile, cookies, cached tokens or account settings are packaged.
